## Projects

### [Monte Carlo Risk Simulation](./monte_carlo-simulation/)
Probabilistic simulation engine that models uncertain future outcomes using
Geometric Brownian Motion and quantifies risk through Value at Risk (VaR) analysis.
Generates 1,000 simulation paths and produces a full statistical summary.

**Skills:** NumPy, matplotlib, statistical modelling, Monte Carlo methods

---

### [Data Dashboard](./stock-dashboard/)
Automated data pipeline that fetches real-world time-series data via API,
computes trend indicators (moving averages), and renders a three-panel
analytical dashboard with return distribution analysis.

**Skills:** pandas, yfinance, matplotlib, data cleaning, API integration
